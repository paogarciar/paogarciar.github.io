# Portfolio (GitHub Pages)

Static site: index.html, three case-study pages and style.css. No build step.
Each case-study page embeds its YouTube demo (video ids are in the iframe `src`).

## Publish
1. Create a repository named `paogarciar.github.io` (or use any repo and enable Pages).
2. Put these files in the repo root, commit and push to `main`.
3. Settings > Pages > Deploy from branch > `main` / root. The site is at https://paogarciar.github.io

## Change a demo video
Edit the id in the `iframe` and the "Watch on YouTube" link of that case-study page, and the video is replaced.
